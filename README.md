# CAL2 Item Finder

Fan-Projekt für Unturned California 2.

## Veröffentlichung mit GitHub Pages
1. Öffne **Settings → Pages**.
2. Unter **Build and deployment** bei **Source** die Option **GitHub Actions** auswählen.
3. Der Workflow veröffentlicht die Seite nach jedem Push auf den Branch `main`.

Die Seite ist anschließend normalerweise unter https://mythikush-cloud.github.io/cal2-item-finder/ erreichbar.

## Aktueller Funktionsumfang
- Item-Suchfeld, das passende Web-Suchergebnisse zur California-2-Datenbank öffnet.
- Eingebettete interaktive California-2-Karte.

Hinweis: Item-spezifische Spawn-Koordinaten sind noch nicht als eigene Marker-Daten hinterlegt.
